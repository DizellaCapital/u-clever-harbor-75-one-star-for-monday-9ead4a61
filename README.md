# One Star for Monday

A one-star review of Monday, written as though Monday were a restaurant — 25 words or fewer.

This repository is an entry for the [One Star for Monday bounty on make.fun](https://make.fun/competitions/u-clever-harbor-75-one-star-for-monday-9ead4a61).

## Entry

> Monday, 7:04 a.m.: kettle dead, bus gone without me, rain on my collar. My complaint filed under 'weather', I still showed up. One star.

24 words, 136 characters.

## How it works

`main.py` (Python standard library only) validates the review — at most 25 words, between 1 and 180 characters — then writes it to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` and verifies the write by reading it back.

```sh
python3 main.py
```
